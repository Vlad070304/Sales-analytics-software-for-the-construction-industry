# BuildSales Insight

Локальний десктопний застосунок для обліку та аналізу продажів у будівельній галузі. Проєкт не використовує HTTP, браузер чи мережевий сервер: усі операції виконуються безпосередньо в застосунку та SQLite-базі.

## Можливості

- внесення й зберігання продажів будівельних матеріалів;
- панель ключових показників і графіків продажів;
- прогноз попиту методом трендово-сезонної декомпозиції;
- індекс ризику дефіциту матеріалу з урахуванням волатильності, запасів та терміну постачання;
- оцінювання ефективності менеджерів продажів.
- локальний імпорт історії продажів із CSV із перевіркою даних.
- експорт поточно відфільтрованих продажів до CSV;
- резервне копіювання SQLite-бази, журнал операцій і налаштування ваг CPRI.

## Запуск

Потрібен Python 3.11+; зовнішні бібліотеки не потрібні.

Найпростіший варіант у Windows — двічі натиснути [run.bat](D:\MAGISTERA\run.bat). Вікно програми відкриється автоматично.

Якщо Windows не може знайти Python, встановіть його з [офіційного сайту](https://www.python.org/downloads/) і під час встановлення позначте **Add Python to PATH**.

Альтернативний запуск через PowerShell:

```powershell
python -m app.desktop
```

Формат імпортного CSV наведено в [docs/import-format.md](docs/import-format.md).
Заплановані напрями розвитку — у [docs/improvement-roadmap.md](docs/improvement-roadmap.md).

Відкриється вікно застосунку. Під час першого запуску буде створено SQLite-базу з демонстраційними даними.

## Структура

```
app/          прикладний код, інтерфейс Tkinter і аналітика
tests/        автоматизовані перевірки аналітичних алгоритмів
docs/         опис моделей та метрик для магістерської роботи
```
