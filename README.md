# BuildSales Insight

Вебзастосунок для обліку та аналізу продажів у будівельній галузі. Проєкт поєднує прикладну частину (збереження продажів, клієнтів і матеріалів) з аналітичним модулем для прогнозування попиту та оцінювання ризиків.

## Можливості

- внесення й зберігання продажів будівельних матеріалів;
- панель ключових показників і графіків продажів;
- прогноз попиту методом трендово-сезонної декомпозиції;
- індекс ризику дефіциту матеріалу з урахуванням волатильності, запасів та терміну постачання;
- оцінювання ефективності менеджерів продажів.

## Запуск

Потрібен Python 3.11+; зовнішні бібліотеки не потрібні.

```powershell
python -m app.server
```

Відкрийте `http://127.0.0.1:8000` у браузері. Під час першого запуску буде створено SQLite-базу з демонстраційними даними.

## Структура

```
app/          прикладний код і HTTP API
static/       інтерфейс панелі аналітики
tests/        автоматизовані перевірки аналітичних алгоритмів
docs/         опис моделей та метрик для магістерської роботи
```
