# Як запустити BuildSales Insight

## Найпростіший спосіб

1. Відкрийте папку проєкту `D:\MAGISTERA`.
2. Двічі натисніть **START_APPLICATION.bat**.
3. Дочекайтеся появи вікна **BuildSales Insight**.

Перший запуск автоматично створює локальну базу даних із демонстраційними продажами. Програма не використовує браузер, HTTP або інтернет.

## Якщо програма не запустилася

Встановіть Python 3.11 або новіший з [python.org](https://www.python.org/downloads/). Під час інсталяції обов'язково позначте **Add Python to PATH**, після чого знову відкрийте `START_APPLICATION.bat`.

## Перші дії у програмі

1. Натисніть **«Матеріали»**, щоб перевірити довідник матеріалів, залишки та строки постачання.
2. Натисніть **«Імпортувати CSV»**, якщо потрібно додати історію продажів. Дані спершу відкриються для перевірки, а збереження відбудеться лише після підтвердження.
3. Натисніть **«Застосувати»** у блоці фільтрів, щоб аналізувати конкретний період, категорію, матеріал, клієнта чи менеджера.
4. Двічі натисніть матеріал у таблиці CPRI, щоб переглянути пояснення оцінки ризику закупівлі.
5. Натисніть **«Експортувати CSV»**, щоб зберегти поточний відфільтрований набір продажів.

## Перевірка якості проєкту

Двічі натисніть **CHECK_PROJECT.bat**. Він по черзі запускає Pylint, Ruff і всі автоматизовані тести. Успішна перевірка завершується повідомленням `All quality checks passed.`
