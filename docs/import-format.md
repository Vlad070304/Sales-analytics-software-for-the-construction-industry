# Імпорт продажів із CSV

У десктопному застосунку натисніть **«Імпортувати CSV»** і виберіть файл. Застосунок перевірить файл та покаже таблицю-попередній перегляд. Дані буде збережено лише після натискання **«Підтвердити імпорт»**. Імпорт відбувається локально, без надсилання даних у мережу.

## Обов'язкові колонки

| Колонка | Формат | Приклад |
| --- | --- | --- |
| `sold_at` | дата ISO `YYYY-MM-DD` | `2026-09-21` |
| `material` | точна назва наявного матеріалу | `Цемент М500` |
| `manager` | текст | `Ірина Коваль` |
| `customer` | текст | `ТОВ Будмонтаж` |
| `quantity` | додатне число | `12.5` |
| `unit_price` | число не менше нуля | `190.00` |

Приклад файлу:

```csv
sold_at,material,manager,customer,quantity,unit_price
2026-09-21,Цемент М500,Ірина Коваль,ТОВ Будмонтаж,12.5,190.00
2026-09-22,Газоблок D500,Олег Марченко,ПП Фасад,18,2450.00
```

Підтримуються кодування UTF-8 та Windows-1251. Кількість і перші помилки некоректних рядків застосунок покаже до збереження; коректні рядки можна підтвердити або скасувати.
