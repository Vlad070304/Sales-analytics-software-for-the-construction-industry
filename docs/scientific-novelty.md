# Наукова новизна дослідження

## Запропонований результат

У роботі запропоновано **CPRI (Construction Procurement Risk Index)** — адаптивний індекс пріоритету закупівлі для будівельних матеріалів. На відміну від звичайного контролю залишків, CPRI визначає ризик не за одним порогом запасу, а за інтегрованим впливом прогнозу попиту, сезонності, мінливості продажів і часу постачання.

Алгоритм реалізовано у `app/analytics.py` функцією `shortage_risk`, а його результати застосунок показує для кожного матеріалу.

## Формальна модель

Для матеріалу `i` індекс визначено так:

`CPRI_i = 100 · (0.40D_i + 0.25V_i + 0.20L_i + 0.15S_i)`.

Складові нормовано до діапазону `[0; 1]`:

- `D_i = min(1, (F_i · LT_i / 30) / Stock_i)` — частка запасу, яку може використати прогнозований попит за період постачання;
- `V_i = min(1, σ(Q_i) / mean(Q_i))` — нестабільність помісячного попиту через коефіцієнт варіації;
- `L_i = min(1, LT_i / 30)` — відносна тривалість поставки;
- `S_i = min(1, max(0, F_i / mean(Q_i) - 1))` — сезонне прискорення, тобто очікуване зростання проти середнього рівня.

Тут `F_i` одержують трендово-сезонним прогнозом, а `Q_i` — історичним рядом продажів. Ваги фіксують пріоритет: забезпеченість запасом є найважливішою, а сезонне прискорення не може штучно збільшувати ризик у період спаду.

## У чому полягає новизна

1. Запропоновано єдиний кількісний індикатор, що зводить ринкову динаміку та операційні обмеження закупівлі в порівнювану шкалу 0–100.
2. На відміну від класичної точки замовлення, модель використовує саме **сезонно скоригований прогноз**, а не середнє історичне споживання.
3. Уведено компонент сезонного прискорення `S_i`, що дає системі змогу відрізняти матеріал із тим самим залишком, але з очікуваним весняно-літнім зростанням попиту.
4. Сформовано пояснюваний алгоритм: кожен компонент індексу доступний для інтерпретації, тому рішення щодо закупівлі можна обґрунтувати для менеджера або комісії.

## Практична перевірка гіпотези

Гіпотеза дослідження: ранжування CPRI зменшує кількість ситуацій дефіциту порівняно з ранжуванням лише за мінімальним залишком. Для експерименту слід на історичних даних змоделювати два сценарії закупівель з однаковим бюджетом: базовий (за запасом) і запропонований (за CPRI). Порівнюють кількість дефіцитів, втрачену виручку та середній надлишковий запас. Гіпотеза підтверджується, якщо CPRI знижує дефіцити без статистично значущого збільшення надлишкових запасів.

## Межі застосовності

Модель призначена для матеріалів із щомісячною історією продажів. Ваги є параметрами, які доцільно калібрувати на даних конкретного підприємства; застосунок підтримує їх контрольоване налаштування з перевіркою невід'ємності й суми ваг 1. Отже, індекс є інструментом підтримки рішень, а не автоматичною заміною відповідального менеджера.
